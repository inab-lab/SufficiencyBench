# SufficiencyBench version 1.0 (superseded)

This folder holds version 1.0 of the benchmark (1,390 / 278 / 1,112 train / val / test questions). It is superseded by version 1.1 in `../sufficiencybench/`.
It is kept because the frontier API runs reported in the paper were scored on this version, before the whitespace normalisation introduced in version 1.1.
Use `../sufficiencybench/` for all new work.
